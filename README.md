# Questões Cristalina

App de estudo para Analista de TI, Câmara Municipal de Cristalina/GO (prova 20/12/2026).

**Abrir no celular:** https://claude.ai/artifact/5RYVmoB7jeUeQZF9qogJT4
(ou a página-atalho: https://crikz.github.io/questoes-cristalina/)

Use o navegador do celular (Chrome) logado no claude.ai e adicione à tela inicial. O app do Claude abre em branco.

`app.html` é o código do artefato; as questões e respostas ficam no banco do artefato, não aqui.
